Translate: f(x) + d moves the graph up (d > 0) or down (d < 0). The slope stays the same.

Dilate: a · f(x) stretches when |a| > 1, compresses when 0 < |a| < 1, and reflects across the x-axis when a < 0.

For f(x) = x: a · f(x) + d = ax + d, with slope a and y-intercept (0, d).

Parallel lines have the same slope. Put the point into y = mx + b to find b.
