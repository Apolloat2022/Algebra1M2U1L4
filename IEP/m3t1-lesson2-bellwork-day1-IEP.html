Bell Work: Review

Warm up while attendance is taken. Answer all 4 questions, then submit to see which ones you got right.

Each question has 3 choices. Use the reminders below, and press Read aloud to hear a question.

Standard → slope-intercept: subtract the x-term, then divide every term by the number with y.

Point-slope → slope-intercept: distribute, then add or subtract to get y alone.

Intercepts: x-intercept: put 0 in for y. y-intercept: put 0 in for x.

Solve a formula for a letter: undo everything around that letter, doing the same to both sides.
