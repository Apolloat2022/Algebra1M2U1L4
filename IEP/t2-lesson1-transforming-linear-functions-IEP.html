Day 1 · Bell Work · Review

Warm up: work these on your own

1. What is the slope between (1, 2) and (4, 11)?

Formula: m = (y₂ − y₁) ÷ (x₂ − x₁)

3
1. Label the points: (x₁, y₁) = (1, 2) and (x₂, y₂) = (4, 11).
2. Subtract the y-values: 11 − 2 = 9. Subtract the x-values: 4 − 1 = 3.
3. Divide: 9 ÷ 3 = 3.

2. What is the y-intercept of y = 3x − 7?

Formula: y = mx + b, y-intercept (0, b)

(0, −7)
1. Match y = 3x − 7 to y = mx + b: m = 3 and b = −7.
2. The y-intercept is (0, b) = (0, −7).

3. f(x) = 2x + 1. What is f(−3)?

Formula: put the number in for x

−5
1. Replace x with (−3): f(−3) = 2(−3) + 1.
2. Multiply: 2(−3) = −6.
3. Add: −6 + 1 = −5.

4. Which equation in slope-intercept form is parallel to y = 3x + 1 and passes through (1, 5)?

Formula: parallel: same slope · y = mx + b

y = 3x + 2
1. Parallel to y = 3x + 1 means the same slope: m = 3.
2. Put in the point (1, 5): 5 = 3(1) + b.
3. 5 = 3 + b, so b = 2: y = 3x + 2.
Have this up as students walk in (about 5 minutes). The same 4 questions are on the online IEP Day 1 bell work, which shows the same formula under each question and these steps after each answer. Click to reveal one answer at a time; read each step aloud and point to where the formula is used.

Day 2 · Bell Work · Review

Warm up: work these on your own

1. f(x) = x is translated up 4 units. Which equation is the new function?

Formula: up d: g(x) = f(x) + d

g(x) = x + 4
1. Up 4 means add 4 to every output: g(x) = f(x) + 4.
2. Replace f(x) with x: g(x) = x + 4.

2. The point (2, 5) is translated down 3 units. Where does it go?

Formula: down d: (x, y) → (x, y − d)

(2, 2)
1. x stays the same: x = 2.
2. Down 3, so subtract 3 from y: 5 − 3 = 2.
3. The new point is (2, 2).

3. f(x) = 2x − 1. What is the slope of g(x) = f(x) + 6?

Formula: moving up or down does not change the slope

2
1. g(x) = 2x − 1 + 6 = 2x + 5.
2. The number with x is still 2, so the slope is 2.

4. The graph of f(x) = x is transformed to make g(x) = x − 2. Which describes the transformation?

Formula: outside: + moves up, − moves down

A translation down 2 units
1. The − 2 is outside f(x): it changes every output (y-value).
2. Minus means down: a translation down 2 units.

Day 3 · Bell Work · Review

Warm up: work these on your own

1. f(x) = x and g(x) = 3f(x). What is the slope of g(x)?

Formula: for f(x) = x, a · f(x) = ax has slope a

3
1. Replace f(x) with x: g(x) = 3x.
2. The number with x is 3, so the slope is 3.

2. How is g(x) = −2f(x) related to f(x) = x?

Formula: a · f(x): |a| > 1 stretches, a < 0 flips

Stretched vertically by 2 and reflected across the x-axis
1. a = −2. The size, 2, is more than 1: stretched by 2.
2. The sign is negative: reflected (flipped) across the x-axis.

3. Which function is a vertical compression of f(x) = x?

Formula: a · f(x): 0 < a < 1 compresses

g(x) = ½f(x)
1. Look for a number between 0 and 1 in front of f(x).
2. ½ is between 0 and 1, so g(x) = ½f(x) compresses.

4. Which function is a reflection of f(x) = x across the x-axis and a vertical dilation by a factor of 2?

Formula: a · f(x): a < 0 reflects, |a| > 1 stretches

g(x) = −2x
1. Reflect: a is negative. Factor of 2: |a| = 2.
2. So a = −2 and g(x) = −2x.

Topic 2 Lesson 1 · Steps

How to read g(x) = a · f(x) + d

1. Start with f(x) = x: slope 1, through (0, 0).

2. a is the new slope. A negative a flips the line.

3. d moves the line up (+) or down (−). The y-intercept is (0, d).

4. Plot (0, d), then count the slope a.

Leave this slide up, or give students a printed copy, while they work.

Move f(x) = x up 5

Up means +: add 5 to every output (y).

−4−4+ 51
−1−1+ 54
22+ 57
p(x) = f(x) + 5 = x + 5

Slope: still 1. y-intercept: (0, 0) → (0, 5).

We do · Together

Move j(x) = 2x − 1 down 4

Down means −: subtract 4 from every output.

r(x) = j(x) − ____

r(x) = j(x) − 4

Simplify: 2x − 1 − 4 = ____

r(x) = 2x − 5  (−1 − 4 = −5)

Slope ____   y-intercept ____

slope 2, (0, −1) → (0, −5)
Students fill in the blanks on their paper first, then reveal. On the graph, each click moves one point down 4: count 4 squares down from the black point to the blue point. Then the blue line r(x) appears.

I do · Stretch

Multiply f(x) = x by 4

Multiply every output by 4.

a(x) = 4x

The slope is now 4: steeper.

With −4, the line also flips:

c(x) = −4x
All three lines pass through (0, 0): multiplying 0 gives 0.

You do · Try it

Describe the change and write g(x)

1. g(x) = 2 · f(x) + 7

stretch by 2, up 7: 2x + 7

2. g(x) = {{1|2}} · f(x) − 3

compress by {{1|2}}, down 3: {{1|2}}x − 3

Check it · Step by step

Describe the change and write g(x)

1. g(x) = 2 · f(x) + 7

Step 1. f(x) = x, so write x in its place: g(x) = 2x + 7.

Step 2. The number multiplied is a = 2. It is the new slope. 2 is more than 1, so the line stretches (gets steeper).

Step 3. The number added is d = +7. Plus means the line moves up 7. It crosses the y-axis at (0, 7).

stretch by 2, up 7: g(x) = 2x + 7

2. g(x) = {{1|2}} · f(x) − 3

Step 1. Write x in place of f(x): g(x) = {{1|2}}x − 3.

Step 2. a = {{1|2}} is between 0 and 1, so the line compresses (gets less steep). The slope is {{1|2}}.

Step 3. d = −3. Minus means the line moves down 3. It crosses the y-axis at (0, −3).

compress by {{1|2}}, down 3: {{1|2}}x − 3
For the teacher or assistant: click once for each step. Read the step aloud, and before each click ask the student what to do next. Students check their own paper and fix any mistake in a different color.

We do · Parallel line

Parallel to y = −3x − 1, through (−1, 5)

Step 1: same slope.  m = ____

m = −3

Step 2: 5 = −3(−1) + b, so b = ____

b = 2

Step 3: write it.

y = −3x + 2
Parallel lines have the same slope; only b changes.

You do · Try it

Parallel to y = 2x

1. Through (0, 4)

y = 2x + 4

2. Through (2, 0)

0 = 2(2) + b

y = 2x − 4

Check it · Step by step

Parallel to y = 2x

1. Through (0, 4)

Step 1. Parallel means the same slope: m = 2.

Step 2. Put x = 0 and y = 4 into y = mx + b: 4 = 2(0) + b.

Step 3. 2(0) = 0, so 4 = b.

Step 4. Write the slope and b: y = 2x + 4.

y = 2x + 4

2. Through (2, 0)

Step 1. Same slope: m = 2.

Step 2. Put x = 2 and y = 0 into y = mx + b: 0 = 2(2) + b.

Step 3. Multiply: 0 = 4 + b.

Step 4. Subtract 4 from both sides: −4 = b.

y = 2x − 4
For the teacher or assistant: click once for each step. Read the step aloud, and before each click ask the student what to do next. Students check their own paper and fix any mistake in a different color.

Exit Ticket

Show what you know

1. g(x) = f(x) + 6. Up or down? How far?

up 6

1. The + 6 is outside f(x), so the graph moves up or down.

2. Plus means up: up 6.

2. What is the slope of g(x) = 5 · f(x)?

5

1. Replace f(x) with x: g(x) = 5x.

2. The number with x is 5, so the slope is 5.

3. Write the line parallel to y = 4x + 1 through (0, −2).

y = 4x − 2

1. Parallel means the same slope: m = 4.

2. Put x = 0, y = −2 into y = mx + b: −2 = 4(0) + b, so b = −2.

3. Write it: y = 4x − 2.
