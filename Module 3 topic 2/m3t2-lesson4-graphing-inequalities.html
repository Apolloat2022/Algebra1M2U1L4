Activity 4.1 · Linear Inequalities in Two Variables · SE pp. 451–453 · ★ Essential

Kai needs at least 20 points

Two-point shots x, three-point shots y: 2x + 3y = 20

(6, 2): 18, no · (7, 2): 20, yes · (7, 4): 26, yes

At least 20: 2x + 3y ≥ 20

Only whole numbers of shots make sense, so (6.5, 5.5) is not a real answer.

Questions 1–11. Points on or above the line meet the goal. The equation's solutions are only on the line; the inequality's fill a region.

Activity 4.2 · Determining the Graphs · SE pp. 454–455 · ★ Essential

Graph y > 4x − 6

A boundary line splits the plane into two half-planes.

Dashed for > or <: points on the line are not solutions. Solid for ≥ or ≤.

Test (0, 0): 0 > 4(0) − 6, 0 > −6 true

Shade the half-plane that contains (0, 0).

Questions 1–3. If the boundary line goes through (0, 0), test a different point.

Activity 4.2 · Practice · SE pp. 455–457 · ★ Essential

Graph each inequality

a. y > x + 3

dashed · test (0, 0): 0 > 3 false

shade above

b. y ≤ −⅓x + 4

solid · test (0, 0): 0 ≤ 4 true

shade below

c. 2x − y < 4

rewrite: y > 2x − 4

dashed · 0 < 4 true

shade above
Questions 4–6. Worked Example: a solid line y = −(3/2)x − 5 with the half-plane above shaded is y ≥ −(3/2)x − 5.

Activity 4.3 · Interpreting the Graph · SE pp. 459–460 · ★ Essential

César's $50 phone card

Table: (0, 100), (50, 80), (250, 0) → U.S. calls 20¢ a minute, Mexico 50¢ a minute

0.2x + 0.5y ≤ 50

(100, 80): $60, no · (90, 55): $45.50, yes

Questions 1–6. On the line: uses exactly $50. Below: money left over. Above: costs more than the card holds.

Talk the Talk · There's a Fine Line · SE pp. 461–462 · ★ Essential

Compare the solution sets

Equation or inequalitySolution set
x + y = 0the points on the line
x + y ≥ 0the line and the half-plane above it
x + y ≤ 0the line and the half-plane below it
x + y > 0the half-plane above, line not included
x + y < 0the half-plane below, line not included
Questions 1–4 use x + y = 12; test (0, 0) for each.

Essential Question · Answered

What does the graph of a linear inequality in two variables look like?

Graph the boundary line: solid for ≤ or ≥, dashed for < or >.

Test a point. If it is a solution, shade its half-plane; if not, shade the other one.

Have students answer the Essential Question on the lesson opener page.
