Welcome to Topic 2. Students transform the parent function f(x) = x: vertical translations f(x) + d (blue) and vertical dilations a · f(x) (orange). They prove a line and its translation are parallel and write equations of parallel lines. Three days on the 150-day calendar: Day 1 Getting Started and Activity 1.1; Day 2 Activities 1.2 and 1.3; Day 3 Activity 1.4, Activity 1.5 and Talk the Talk. Materials: masking tape and markers for the floor coordinate plane, the Problem-Solving Model Graphic Organizer.

Lesson 1 · SE p. 269

Today you will…

1. Determine the effects on the graph of a linear function when f(x) is replaced by f(x) + d or a · f(x).

2. Graph transformations of the parent function and describe them.

3. Prove that a line and its vertical translation are parallel.

4. Write the equation of a line parallel to a given line through a given point.

Key term: parent function, the simplest function of its type. f(x) = x is the parent of the linear function family.

Read each objective aloud as it appears.

Topic 2 Lesson 1 · Key Vocabulary

Key vocabulary

Parent function

The simplest function of its type.

f(x) = x

Transformation

A change to a graph: move it, stretch it, or flip it.

Vertical translation

Moves the graph up or down d units. Same slope.

f(x) + 5

Vertical dilation

Stretches or compresses the graph. Changes the slope.

3 · f(x)

Reflection

Flips the graph across the x-axis (a negative factor).

−f(x)

Parallel lines

Lines with the same slope that never meet.

y = 2x + 3, y = 2x − 5

Day 1 · Getting Started · Dilations · SE p. 271 · ★ Essential

Multiply every y-coordinate by 2, then by −2

The points move straight up or down, away from the x-axis (twice as far).

× 2: E(−8, −16) and F(8, 16). EF is steeper: a vertical stretch.

× (−2): G(−8, 16) and H(8, −16). Steeper and reflected across the x-axis.

All three segments pass through the origin, which doesn't move.

Ask: Which point did not move? (The origin: 0 times 2 is still 0.) What does multiplying by a negative do? (It reflects across the x-axis.)

Day 1 · Activity 1.1 · Definition · SE p. 273 · ★ Essential

Vertical translation: y = f(x) + d

d > 0: the graph moves up d units. d < 0: it moves down.

Only the output values change. The slope stays the same, so the new line is parallel to the original.

For f(x) = x: f(x) + d = x + d, a line with slope 1 and y-intercept (0, d).

Have students copy the definition. Stamp the learning: a vertical translation changes the y-intercept, not the slope.

Day 1 · Activity 1.1 · Questions 5–6 · SE p. 274 · ★ Essential

Translate j(x) = 2x − 1 up 4 and down 4

Up 4:

q(x) = j(x) + 4 = 2x + 3

Down 4:

r(x) = j(x) − 4 = 2x − 5

All three have slope 2 and different y-intercepts: (0, −1), (0, 3), (0, −5). They are parallel, so they never intersect.

Ask Yourself: Will the graphs of j(x), q(x) and r(x) ever intersect? Ask: How can you tell from the equations? (Same slope, different y-intercepts.)

A line and its vertical translation are parallel.

Day 2 · Activity 1.2 · Slopes of Parallel Lines · SE p. 275 · ★ Essential

Will the graphs of j(x) and q(x) ever intersect?

j(x) = 2x − 1    q(x) = 2x + 3

No. Both lines have slope 2 and stay 4 units apart, so they are parallel.

Prove it for any line. Translate line AB up a units to make line A′B′.

Pre-image: A(x₁, y₁), B(x₂, y₂)

Image: A′(x₁, y₁ + a), B′(x₂, y₂ + a)

Slope of the image:

((y₂ + a) − (y₁ + a)) ÷ (x₂ − x₁)
= (y₂ − y₁) ÷ (x₂ − x₁)
Activity 1.2, 15–20 minutes. The a's cancel, so the slopes are the same: the image is parallel to the pre-image. Ask: Why did the x-coordinates stay the same? (A vertical translation moves only up or down.)

Catalina

Parallel to y = ½x + 3 through (2, 9): the point on the line at x = 2 is (2, 4), so translate up 5.

y = ½x + 8

Now you: parallel to y = −3x − 1 through (−1, 5).

Day 2 · Activity 1.3 · Definition · SE p. 279 · ★ Essential

Vertical dilation: y = a · f(x)

|a| > 1: the graph stretches vertically (steeper).

0 < |a| < 1: it compresses vertically (less steep).

a < 0: it also reflects across the x-axis.

For f(x) = x, the new slope is a; the y-intercept stays (0, 0).

Have students copy the definition. Watch for students who say the slope 'increases' when a = −3: it gets steeper, but the slope is −3.

Day 2 · Summary

Translations vs. dilations

Translation f(x) + d

Moves the line up or down. Same slope; new y-intercept. Parallel lines.

Dilation a · f(x)

Stretches, compresses or reflects. New slope; for f(x) = x the y-intercept stays (0, 0).

Parallel line through a point: keep the slope, then find b with the point.

To close Day 2, have students reread the Essential Question. End of Day 2.

Day 3 · Activity 1.4 · Question 2 · SE p. 281 · ★ Essential

What do a and d do in g(x) = a · f(x) + d?

a

Changes the slope. For f(x) = x the slope becomes a: steeper when |a| > 1, less steep when 0 < |a| < 1, reflected when a < 0.

Does not change the y-intercept.

d

Does not change the slope.

Moves the y-intercept to (0, d): up when d > 0, down when d < 0.

TE correction: the teacher guide says the slope 'increases' or 'decreases'; it means steepness. For a = −3 the slope is −3.

Essential Question · Answered

How can you transform a function?

Translation y = f(x) + d: moves the graph up (d > 0) or down (d < 0). The slope stays the same, so the new line is parallel; the y-intercept changes.

Dilation y = a · f(x): stretches (|a| > 1) or compresses (0 < |a| < 1) the graph; a < 0 also reflects it across the x-axis. The slope changes; for f(x) = x it becomes a.

Have students answer the Essential Question on the lesson opener page.
