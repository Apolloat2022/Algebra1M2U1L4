Lesson 1 · SE p. 393

Today you will…

1. Write equations in standard form and use the intercepts to graph them.

2. Write a system of equations to represent a problem context.

3. Use a graph to solve a system of linear equations and interpret the solution.

4. Use slopes and y-intercepts to tell whether a system has one, no, or infinite solutions.

New key terms: system of linear equations · consistent systems · inconsistent systems

Read each objective aloud as it appears.

Lesson 1 · Key Vocabulary

Key vocabulary

System of linear equations

Two or more linear equations about the same quantities.

y = x + 1, y = −2x + 4

Solution of a system

A point that makes every equation true: where the lines cross.

(1, 2)

Intercepts

Where a line crosses the axes. Set the other variable to 0.

5s + 10a = 3000 → (600, 0), (0, 300)

Consistent

The system has at least one solution.

lines cross or are the same

Inconsistent

The system has no solution.

parallel lines

Slope

Rate of change. Same slope means parallel or the same line.

y = 10x + 25 has slope 10

Getting Started · Ticket Tabulation · SE p. 394 · ★ Essential

Raise $3000 with $5 student and $10 adult tickets

1. Write an equation for the situation. Let s = student tickets and a = adult tickets.

5s + 10a = 3000

2. Some combinations that reach the goal

600 student, 0 adult

200 student, 200 adult

0 student, 300 adult

3. Classmates get different answers: one equation in two unknowns has many solutions.

Getting Started, about 10 minutes. Collect several combinations on the board; every one is a point on the same line.

Activity 1.1 · Graph Using Intercepts · SE p. 395 · ★ Essential

Standard form: graph with the intercepts

x-intercept: let a = 0: 5s = 3000 → (600, 0)

y-intercept: let s = 0: 10a = 3000 → (0, 300)

Slope = −300/600 = −½: for every 2 more student tickets, 1 fewer adult ticket.

Domain, real world: whole numbers 0 ≤ s ≤ 600. Range: 0 ≤ a ≤ 300.

Questions 1–5. The mathematical function has all real numbers for its domain and range; the situation only allows whole numbers of tickets.

Activity 1.1 · Ethan's Graph · SE pp. 396–397 · ★ Essential

Same equation, axes switched

Ethan: adult tickets on the x-axis

Intercepts (300, 0) and (0, 600)

Slope −2: 1 more adult ticket replaces 2 student tickets.

What stays the same

The same combinations meet the goal; only the axes are switched.

Neither graph shows the money: every point on the line is exactly $3000.

Questions 6–12. Ethan's graph is correct; the domain and range trade places.

Activity 1.2 · Determining the Solution · SE p. 398 · ★ Essential

450 tickets were sold. How many of each?

Second equation: s + a = 450

Two or more linear equations about the same quantities form a system of linear equations.

The lines cross at (300, 150): 300 student and 150 adult tickets.

Check: 5(300) + 10(150) = 3000 ✓ · 300 + 150 = 450 ✓
Questions 1–5. Use graphing technology to find the exact intersection: graph both lines, then use the intersect tool. There is only one solution because the lines cross once.

Activity 1.3 · Samuel and Diego · SE p. 400 · ★ Essential

Both save $10 a week. Samuel starts with $25, Diego with $40.

Samuel: y = 10x + 25

Diego: y = 10x + 40

Same slope (same weekly savings), different y-intercepts (different start).

Parallel lines: they never have the same amount. No solution.
Questions 1–6. Students predict first. Diego is always $15 ahead.

Activity 1.3 · Isabella and Diego · SE pp. 402–404 · ★ Essential

Same start, different rates, then the same rate

Isabella saves $4 a week

y = 4x + 40 and y = 10x + 40

Different slopes, same y-intercept.

One solution: (0, 40), the day they start

Then she saves $4 + $6 = $10 a week

y = 10x + 40 and y = 10x + 40

Same slope, same y-intercept: the same line.

Infinite solutions. Diego's claim is false.
Questions 7–11. Don't forget to define the variables: x = weeks, y = dollars saved.

Essential Question · Answered

How can you solve problems that require two linear functions?

Write an equation for each relationship, graph both on the same plane, and find where they intersect.

The intersection point is the solution: it makes both equations true.

Compare slopes and y-intercepts to know how many solutions to expect.

Have students answer the Essential Question on the lesson opener page.
