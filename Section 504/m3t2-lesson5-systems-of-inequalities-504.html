Lesson 5 · Key Vocabulary

Key vocabulary

System of linear inequalities

Two or more inequalities with the same variables.

200a + 100c ≤ 800, 75a + 50c ≥ 150

Constraint

A limit in the problem.

at most 800 pounds

Solution set

Every point in the overlap of the shaded regions.

the double-shaded region

Overlap

Where both shadings are.

darkest region

Dashed boundary

Points on it are not solutions.

x + y > 1

Verify

Check a point in every inequality.

600 ≤ 800 ✓, 250 ≥ 150 ✓

Activity 5.1 · Determining Solutions · SE pp. 469–470 · ★ Essential

Which trips work?

The inequalities are constraints: they limit where solutions can be.

2 adults, 2 children: 600 ≤ 800 ✓, 250 ≥ 150 ✓ → works

5 adults: 1000 ≤ 800 ✗ → too heavy

More solutions: (1, 2), (0, 3), (3, 2). Not one: (0, 2), only $100.

Questions 1–3. The solution set is the overlap of the two shaded half-planes, in the first quadrant (no negative rafters). The lines meet at (10, −12), which cannot happen here.

Essential Question · Answered

What does the graph of a system of linear inequalities look like, and how can you describe the solution set?

Graph each inequality and shade it. The overlap is the solution set.

A point is a solution only if it makes every inequality true. Points on a dashed line are not solutions.

Have students answer the Essential Question on the lesson opener page.
