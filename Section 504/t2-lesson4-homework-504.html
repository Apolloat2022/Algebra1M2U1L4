Slope from a table or two points: (change in y) ÷ (change in x).

Same slope → parallel. Slopes multiply to −1 → perpendicular. Otherwise neither.

y-intercept: the output when x = 0, the starting amount.

Units: the slope is output units per input unit, for example dollars per ton.
