Students compare horizontal transformations f(x − c) and f(bx) with the vertical ones from Lesson 1. For f(x) = x, a horizontal translation right n matches a vertical translation down n, and a vertical dilation by n matches a horizontal dilation by 1/n, but these pairs do not match for other linear functions. Two days on the 150-day calendar: Day 1 Getting Started and Activity 2.1; Day 2 Activities 2.2, 2.3 and Talk the Talk.

Topic 1 Catch-Up · Lesson 5 · Talk the Talk · Choose Your Medium · SE p. 232

Joey's math quiz

2 points for each correct multiple-choice question, 3 points for each correct short answer. Joey earned 36 points. Let x = multiple-choice correct and y = short answer correct.

2x + 3y = 36

Form: standard form, because the equation comes straight from the context: two kinds of points add up to one total.

Graph: use the intercepts. y = 0 gives (18, 0); x = 0 gives (0, 12).

Talk the Talk, 20–25 minutes. Have pairs complete Questions 1–3, then share. For each context students write an equation, name the form and why, graph it, and explain the graphing method. Ask: Does 2x + 3y = 36 or 3x + 2y = 36 represent this? Which axis is which? Reasoning will vary; using the intercepts is natural because the equation is in standard form. Only whole-number points make sense (Joey can't get half a question right), such as (3, 10) and (9, 6). Note: the student book also lists a bullet about matching transformed graphs to f(x); it doesn't apply to these questions, so skip it.

Key vocabulary

Input

The x-value you put in.

Output

The value that comes out, f(x) or y.

Horizontal translation

Moves the graph left or right.

f(x − 3): right 3

Horizontal dilation

Stretches or compresses the graph toward the y-axis.

f(2x)

Inside vs. outside

Inside the parentheses: input. Outside: output.

Counterexample

One example that shows a rule is not always true.

Day 1 · Activity 2.1 · Definitions · SE p. 291

Horizontal vs. vertical translations

y = f(x − c)

Changes the inputs. c > 0: shift right c. c < 0: shift left.

y = f(x) + d

Changes the outputs. d > 0: shift up d. d < 0: shift down.

For f(x) = x: right n = down n, and left n = up n.

Does that work for every linear function?

Watch the sign: f(x − 3) moves right 3, f(x + 3) moves left 3.

Day 1 · Activity 2.1 · Questions 6–9 · SE pp. 292–294

Try it with j(x) = 2x − 1

Up 4 and left 4:

q(x) = j(x) + 4 = 2x + 3
r(x) = j(x + 4) = 2(x + 4) − 1 = 2x + 7

Right 2 and down 2:

b(x) = j(x − 2) = 2x − 5
v(x) = j(x) − 2 = 2x − 3

Not the same. The lines are parallel with different y-intercepts.

Teacher-guide misconception: students expect left 4 to equal up 4 for every line. It works only for slope 1. Slide typos in the student slides: some items labeled 'a.' are b, c and d.

Day 1 · Activity 2.1 · Summary

Translations of linear functions

Inside the parentheses changes the input (horizontal); outside changes the output (vertical).

f(x − c) moves right c; the sign flips.

Only for f(x) = x does right n match down n.

Topic 1 Catch-Up · Lesson 6 · Getting Started · Well, Are Ya or Aren't Ya? · SE p. 240

Linear or nonlinear? Explain your reasoning.

Scenario A

A tree grows 3.5 inches each year.

Linear. Same change, 3.5 in, every year.

Scenario B

The strength of a medication decreases by 50% each hour it is in the patient's system.

Nonlinear. Half of a smaller amount each hour, so the drop shrinks.

Scenario C

The area of a square depends on its side length.

Nonlinear. A = s2: side 1, 2, 3 gives area 1, 4, 9.

Equation A

y = 14 − 9x

Linear. x has exponent 1; slope −9.

Equation B

y = 2x + 1

Nonlinear. The variable is in the exponent.

Equation C

y = {{1|4}}(x + 7) − 1

Linear. Point-slope structure; slope {{1|4}}.

Getting Started, 10–15 minutes. Have pairs complete Question 1 before you reveal anything, then share as a class. Teacher-guide misconception: students may think that because they know a formula for a relationship, like Scenario C, the relationship must be linear. Have them use the formula to make a table (side 1, 2, 3 → area 1, 4, 9; the differences are 3 and 5, not constant). Ask: What is another way to describe "decreases by 50% each hour"? (Multiplied by one-half each hour.) Which feature identifies whether an equation is a linear function? (The variable's exponent is 1 and it isn't in an exponent.)

Topic 1 Catch-Up · Lesson 6 · Activity 6.1 · Summary

Is the table linear?

1. Check the inputs. If they're not consecutive (or not in order), first differences won't work.

2. Calculate the slope, {{change in y|change in x}}, between every pair of points.

3. If the slope is always the same, the table is linear. Use the slope and a point to find b.

4. It's a direct variation only if it passes through (0, 0): y = kx.

Stamp the learning, from the teacher guide: "If a table represents a linear function, the slope, or average rate of change, is constant between all given points." To close Day 1, have students reread the Essential Question and read the activity summaries to the class. End of Day 1.

Definitions

y = a · f(x): vertical, changes outputs.

Essential Question · Answered

What do horizontal transformations do?

In a · f(b(x − c)) + d, b and c change the inputs (horizontal); a and d change the outputs (vertical).

For f(x) = x: right n = down n, and a vertical dilation by n = a horizontal dilation by 1/n.

For other linear functions these pairs are not the same.
