Inside the parentheses changes the input (horizontal). Outside changes the output (vertical).

f(x − c) moves right c. f(x + c) moves left c. The sign flips.

f(bx) compresses horizontally when |b| > 1 and stretches when 0 < |b| < 1.

Only for f(x) = x: right n = down n, and a vertical dilation by n = a horizontal dilation by 1/n.
