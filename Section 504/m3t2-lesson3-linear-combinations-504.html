Lesson 3 · Key Vocabulary

Key vocabulary

Linear combinations method

Add the equations so one variable drops out.

x + y = 324, x − y = 34

Additive inverses

Two numbers that add to zero.

3y and −3y

Coefficient

The number in front of a variable.

the 7 in 7x

Eliminate

Make a variable drop out.

2y + (−2y) = 0

LCD

Least common denominator: clears fractions.

½ and ¾ → multiply by 4

Standard form

Ax + By = C

2n + 4m = 270

Getting Started · Coding Class · SE p. 434 · ★ Essential

324 students; 9th graders outnumber 10th graders by 34

Take away the extra 34: 324 − 34 = 290

Split evenly: 290 ÷ 2 = 145 tenth graders

179 ninth graders and 145 tenth graders

Check: 179 + 145 = 324 and 179 − 145 = 34

Students reason first, without a system. Ask how they could check.

Activity 3.1 · Combining Linear Systems · SE pp. 435–436 · ★ Essential

Mateo substitutes; Minh adds the equations

Mateo

x = y + 34

(y + 34) + y = 324

y = 145, x = 179

Minh

x + y = 324

x − y = 34

Add: 2x = 358

x = 179, y = 145

Minh's way works because y and −y add to zero. That is the linear combinations method.

Questions 1–4. The solution is (179, 145): 179 ninth graders and 145 tenth graders.

Activity 3.1 · Question 5 · SE p. 436 · ★ Essential

Add the equations, then substitute back

a. −4x + y = 10 and −2x − y = −1

Add: −6x = 9 → x = −1.5

−4(−1.5) + y = 10 → y = 4

(−1.5, 4)

b. −½x + 5y = −6 and ½x + y = −6

Add: 6y = −12 → y = −2

½x − 2 = −6 → x = −8

(−8, −2)
Have students check each solution in both equations.

Activity 3.2 · Using Additive Inverses · SE p. 437 · ★ Essential

Multiply first to make opposites

7x + 2y = 24

4x + y = 15 × (−2): −8x − 2y = −30

Add: −x = −6, so x = 6

7(6) + 2y = 24 → y = −9

(6, −9)

Check: 4(6) + (−9) = 15 ✓

Only one equation needed to change: the 2y was already a multiple of y.

Worked Example and Question 1. Additive inverses: two numbers with a sum of zero.

Activity 3.2 · Both Equations Change · SE pp. 438–439 · ★ Essential

When neither coefficient is a multiple of the other

4x + 2y = 3, 5x + 3y = 4

× 3 and × (−2): 12x + 6y = 9, −10x − 6y = −8

Add: 2x = 1 → x = ½

(½, ½)

4x + 3y = 12, 3x + 2y = 4

× 2 and × (−3): 8x + 6y = 24, −9x − 6y = −12

Add: −x = 12 → x = −12

(−12, 20)
Worked Example 2 and Questions 2–5. Question 3: you could also make the x-terms opposites with × 5 and × (−4).

Activity 3.3 · Applying the Method · SE pp. 440–441 · ★ Essential

Let It Snow: lodging and meals

Get-Away: 2n + 4m = 270

Extended Stay: 3n + 8m = 435

× (−2) the first: −4n − 8m = −540

Add: −n = −105 → n = 105

2(105) + 4m = 270 → m = 15

$105 a night, $15 a meal

Both specials use the same prices, so neither is a better deal per item.

Questions 1–6. Check: 3(105) + 8(15) = 315 + 120 = 435.

Activity 3.4 · Fractions and Linear Combinations · SE pp. 442–443 · ★ Essential

84 bracelets; 49 made so far

x + y = 84

½x + ¾y = 49

Aaliyah: × 4 (the LCD): 2x + 3y = 196

Liam: × (−½) the first equation also works.

× (−2) the first: −2x − 2y = −168

Add: y = 28, then x = 56

56 five-inch and 28 seven-inch bracelets
Questions 1–5. Both students are correct: each step makes a pair of opposite coefficients. Check: ½(56) + ¾(28) = 28 + 21 = 49.

Talk the Talk · There's a Method in My Madness · SE p. 444 · ★ Essential

Which method when?

MethodHowBest when
Graphinggraph both lines, read the intersectionyou want a picture or an estimate; use technology
Substitutionreplace a variable with its equal expressiona variable is already alone, like y = 5x
Linear combinationsadd equations so a variable drops outboth equations are in standard form Ax + By = C
Students describe each method and the kind of system that suits it.

Essential Question · Answered

What are other algebraic strategies for solving systems of equations?

Linear combinations: line up the equations, multiply so one variable has opposite coefficients, then add.

Solve for the remaining variable, substitute back, and check in both equations.
