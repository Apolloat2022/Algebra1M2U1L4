Lesson 1 · Key Vocabulary

Key vocabulary

Solution

A value for the variable that makes the equation true.

x = 2 in x + 3 = 5

Properties of equality

Do the same thing to both sides and the equation stays balanced.

add, subtract, multiply, divide

Distributive property

Multiply the number outside by every term inside.

3(x − 2) = 3x − 6

No solution

No value works. The sides simplify to a false statement.

3 = 4

Infinite solutions

Every value works. Both sides are the same.

2x + 5 = 2x + 5

Coefficient

The number in front of a variable.

the 4 in 4x

Getting Started · Equation Creation · SE p. 346 · ★ Essential

Build harder equations from x = 2

A solution to an equation is a value for the variable that makes the equation a true statement.

a. Add 3 to each side: x + 3 = 5

b. Multiply each side by 4: 4x + 12 = 20

c. Subtract 2x: 2x + 12 = −2x + 20

d. Divide each side by 2: x + 6 = 10 − x

2. Partner check

Substitute 2 into your partner's last equation.

2 + 6 = 10 − 2 → 8 = 8 ✓

Same operation on both sides, to every term, keeps the solution.

Getting Started, 15 minutes. Look for students who multiply or divide only the x-term instead of every term (TE common misconception). Algebra tiles help.

Activity 1.1 · Using Properties to Justify Solutions · SE p. 347 · ★ Essential

Properties of equality

PropertyFor all numbers a, b, and c
additionIf a = b, then a + c = b + c.
subtractionIf a = b, then a − c = b − c.
multiplicationIf a = b, then ac = bc.
divisionIf a = b and c ≠ 0, then a/c = b/c.

These rules keep both sides balanced while you isolate the variable.

Explicit instruction. TE suggestion: make a poster of both property tables; Lessons 2 and 3 use them again.

Activity 1.2 · Solutions to Linear Equations · SE pp. 349–350 · ★ Essential

Can you change the truth of a sentence?

1. 2 = 2

Add x: 2 + x = 2 + x

Multiply by 5: 10 + 5x = 10 + 5x

Still always true.

2. 2 = 3

Add x: 2 + x = 3 + x

Multiply by 5: 5(2 + x) = 5(3 + x)

Still always false.

No solution: no value makes the equation true. Infinite solutions: every value makes it true.

Questions 1–3. Common misconception: 8 = 8 does not mean x = 8; it means the value we substituted works.

Essential Question · Answered

How can you use equations to solve for unknown inputs?

Use properties of equality to isolate the variable, and name the property for each step.

Simplify each side first. Same coefficient and constant: infinite. Same coefficient, different constant: none. Otherwise: one solution.

Show what you know

1. Solve: 7 − 3(p + 2) = 10 − (2p + 5)

−4

2. Solve: 0.5(4x − 6) = −1.5x + 4

x = 2

3. One, none, or infinite? ½(8x + 6) = 2(2x + 1) + 2

No solution

4. Triangle: base 6, height (x + 5). Rectangle: 4 by (x − 1). Equal areas. Find x.

x = 19
Printed copy: EXIT TICKET/T1-Exit-Ticket-Thu-11-05.pdf (written like the End of Topic 1 test). Give about 8 minutes. Work: 1. 1 − 3p = 5 − 2p → −p = 4 → p = −4. 2. 2x − 3 = −1.5x + 4 → 3.5x = 7 → x = 2. 3. 4x + 3 = 4x + 4: same x-coefficient, different constants, so 3 = 4 is never true. 4. ½(6)(x + 5) = 4(x − 1) → 3x + 15 = 4x − 4 → x = 19.

How many solutions?
