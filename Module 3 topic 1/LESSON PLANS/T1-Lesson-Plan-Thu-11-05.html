Objectives (students will…)

  • Write equivalent equations using the properties of equality.
  • Solve linear equations (distributive property, variables on both sides) and name the property for each step.

Q1: verify Harper (−3x + 14 = 18 − 5x) and Sofia (2x = 5 − ½x) both give x = 2 — substitution 8 = 8, 4 = 4, then properties. Read number properties (commutative, associative, distributive).
Q2 pairs, name each property: (b) 0.6(2x + 1) = 4x + 6.2 x = −2; (c) ½x − 6 = 2 + (2x + 1) x = −6.
