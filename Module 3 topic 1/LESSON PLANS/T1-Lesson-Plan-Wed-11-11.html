Lesson Plan · Wednesday, November 11

Algebra I · Mr. Pandey · Module 3, Topic 1, Lesson 3: Modeling Linear Inequalities (Day 1 of 3) · essentials only (✪)

Objectives (students will…)

  • Write and analyze a linear function from a context (rate of change, y-intercept).
  • Use a graph to solve inequalities.
  • Graph solution sets on a number line with open or closed circles.

TEKS

  • A.2C write linear equations from a context
  • A.5B solve linear inequalities in one variable
  • Process: A.1A, A.1D

Key terms

  • linear inequality

Materials

  • Student Edition pp. 371–375 (Getting Started, Activity 3.1)
  • Inequality-words chart (at least ≥, at most ≤, more than >, fewer than <)
  • Rulers for the horizontal-line method
  • Whiteboards

Bell work (on the board)

  • "at least" means which symbol? ≥
  • "no more than" means which symbol? ≤
  • "fewer than" means which symbol? <
  • Solve 3.75b + 25 = 400 b = 100
