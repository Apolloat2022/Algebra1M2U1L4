Review Q1 · like test Q1 · I do

Find a when m(x) = af(x) and f(x) = x

m(x) = a · x, so a is the slope of the line.

slope = (−2 − 4) ÷ (3 − (−6))
= −6 ÷ 9 = −2/3
a = −2/3

Check: the line falls, so a is negative.

Most common error: run over rise (−3/2). Draw the slope triangle between the two labeled points.

Review Q2 · like test Q2 · I do

Bounce house: $75 + $20 per hour, at most 5 hours. Range?

Range = the outputs = the costs (y). Domain = the hours (x).

0 hours: 75 + 20(0) = 75
5 hours: 75 + 20(5) = 175
C. 75 ≤ y ≤ 175

Cross out

Choices about x are the domain, not the range.

A range must start at the fixed fee.

Students cross out the two x-choices first. Two choices left, then evaluate at both ends.

Review Q3 · like test Q3 · I do

Equation and slope of the line shown

Every point has y-value −20: (−40, −20), (0, −20), (40, −20).

y = −20

Rise = 0, so slope = 0.

H. y = −20; slope is zero

HOY VUX: Horizontal → 0 slope → y = # · Vertical → Undefined → x = #.

The real test uses y = 10. Same idea.

Review Q4 · like test Q4 · We do

g(x) = f(x − 3). How did the graph move?

A change inside the parentheses moves the graph left or right.

It moves the opposite way of the sign: x − 3 → right 3.

C. translated right 3 units

Outside, f(x) − 3, would be down 3.

Inside vs. outside

f(x) + 3: up 3

f(x − 3): right 3

f(x + 3): left 3

The real test uses f(x + 1): left 1. Ask: which way does + 1 inside move it?

Review Q5 · like test Q5 · We do

Translate the table 2 units right. New y-intercept?

xf(x)x + 2new point
−2−70(0, −7)
−1−41(1, −4)
0−12(2, −1)
y-intercept = −7

Right 2: add 2 to every x. The y-values don't change.

Find the new point where x = 0: (−2, −7) → (0, −7).

Rule check: f(x) = 3x − 1, g(x) = 3(x − 2) − 1 = 3x − 7.

The real test translates 1 unit right.

Review Q6 · like test Q6 · We do

Graph g(x) = f(2x) when f(x) = x

Put 2x in for x: g(x) = 2x.

x−2−1013
g(x)−4−2026

Plot and connect: a steeper line through (0, 0).

The real test uses f(3x). Common error: drawing slope ½.

Review Q7 · like test Q7 · We do

Crosses the x-axis at −6, perpendicular to y = 3/2x − 1

Perpendicular slope: flip and change the sign: 3/2 → −2/3.

x-axis at −6 means the point (−6, 0).

0 = −2/3(−6) + b → 0 = 4 + b → b = −4
y = −2/3x − 4
Real test: crosses the x-axis at 4, perpendicular to y = −2/3x + 4 (answer y = 3/2x − 6). Don't give that away today.

Review Q8 · like test Q8 · We do

Through (5, 0), parallel to y = −2.4x + 1.6

Parallel: same slope, −2.4.

0 = −2.4(5) + b → 0 = −12 + b → b = 12
y = −2.4x + 12

Check: −2.4(5) + 12 = 0 ✓

Common error: b = −12 (sign slip).

Review Q9 · like test Q9 · You do

Write an equation in point-slope form

Pick two exact grid points: (−2, −3) and (2, 5).

slope = (5 − (−3)) ÷ (2 − (−2)) = 8 ÷ 4 = 2
y − 5 = 2(x − 2)

Also right: y + 3 = 2(x + 2).

On the real test the points are not labeled: find two lattice points first.

Review Q10 · like test Q10 · You do

Select TWO correct statements

The line rises left to right: increasing.

It crosses the x-axis at −4: the zero is −4.

Slope = 2 ÷ 4 = ½ (not 2). y-intercept (0, 2) (not −4).

F and J
Select TWO: both must be right for the point. Zero = x-intercept, never the y-intercept.
