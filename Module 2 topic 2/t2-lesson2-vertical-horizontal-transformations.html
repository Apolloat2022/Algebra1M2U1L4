Students compare horizontal transformations f(x − c) and f(bx) with the vertical ones from Lesson 1. For f(x) = x, a horizontal translation right n matches a vertical translation down n, and a vertical dilation by n matches a horizontal dilation by 1/n, but these pairs do not match for other linear functions. Two days on the 150-day calendar: Day 1 Getting Started and Activity 2.1; Day 2 Activities 2.2, 2.3 and Talk the Talk.

Day 1 · Activity 2.1 · Definitions · SE p. 291

Horizontal vs. vertical translations

y = f(x − c)

Changes the inputs. c > 0: shift right c. c < 0: shift left.

y = f(x) + d

Changes the outputs. d > 0: shift up d. d < 0: shift down.

For f(x) = x: right n = down n, and left n = up n.

Does that work for every linear function?

Watch the sign: f(x − 3) moves right 3, f(x + 3) moves left 3.

Day 1 · Activity 2.1 · Questions 6–9 · SE pp. 292–294

Try it with j(x) = 2x − 1

Up 4 and left 4:

q(x) = j(x) + 4 = 2x + 3
r(x) = j(x + 4) = 2(x + 4) − 1 = 2x + 7

Right 2 and down 2:

b(x) = j(x − 2) = 2x − 5
v(x) = j(x) − 2 = 2x − 3

Not the same. The lines are parallel with different y-intercepts.

Teacher-guide misconception: students expect left 4 to equal up 4 for every line. It works only for slope 1. Slide typos in the student slides: some items labeled 'a.' are b, c and d.

Day 1 · Activity 2.1 · Summary

Translations of linear functions

Inside the parentheses changes the input (horizontal); outside changes the output (vertical).

f(x − c) moves right c; the sign flips.

Only for f(x) = x does right n match down n.

End of Day 1.

Added for this deck; not from the textbook. Have this up as students walk in; they work silently while you take attendance (about 5 minutes). The same 4 questions are on the online Day 2 bell work. Reveal the answers one at a time. Answer key: 1. A horizontal translation right 5 subtracts 5 from the input: f(x − 5). 2. f(x − 5) = x − 5 = f(x) − 5, a vertical translation down 5. 3. 2(x + 4) − 1 = 2x + 8 − 1 = 2x + 7. 4. f(2x) = 2x and 2f(x) = 2x. For the parent function they match.

For f(x) = x: a vertical dilation by n = a horizontal dilation by 1/n.

Definitions

y = a · f(x): vertical, changes outputs.
y = f(bx): horizontal, changes inputs; |b| > 1 compresses, 0 < |b| < 1 stretches, b < 0 reflects across the y-axis.

Ask: Why are the tables different if the graphs are the same? (They list different points of the same line.)

Day 2 · Activity 2.2 · Question 4 · SE p. 297

Does this hold for any linear function?

Counterexample: m(x) = 2x − 1

3 · m(x) = 6x − 3
m(3x) = 6x − 1

No. The graphs are parallel, not the same. It works only for the parent function.

Counterexamples will vary; any linear function other than f(x) = x works.

Essential Question · Answered

What do horizontal transformations do?

In a · f(b(x − c)) + d, b and c change the inputs (horizontal); a and d change the outputs (vertical).

For f(x) = x: right n = down n, and a vertical dilation by n = a horizontal dilation by 1/n.

For other linear functions these pairs are not the same.

Have students answer the Essential Question on the lesson opener page.
