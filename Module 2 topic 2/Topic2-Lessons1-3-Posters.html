Vertical Translation

y = f(x) + d

d > 0

Moves up.
f(x) + 4: every point up 4.

d < 0

Moves down.
f(x) − 4: every point down 4.

What changes

The outputs (y-values) and the y-intercept, which moves to (0, d).

What stays

The slope. A line and its vertical translation are parallel: they never meet.

Example: j(x) = 2x − 1 up 4 → j(x) + 4 = 2x + 3

Vertical Dilation

y = a · f(x)

|a| > 1

Stretch: steeper.
3 · f(x) = 3x

0 < |a| < 1

Compress: flatter.
⅓ · f(x) = ⅓x

a < 0

Reflect across the x-axis.
−2 · f(x) = −2x

What changes

Every output is multiplied by a. For f(x) = x, the slope becomes a.

What stays

The origin (0, 0) doesn't move: a · 0 = 0.

Example: (2, 5) is on f(x), so (2, −10) is on −2 · f(x).

Horizontal Translation

y = f(x − c)

Inside the parentheses, the sign flips!

f(x − 3)

Moves right 3.
Minus inside → right.

f(x + 3)

Moves left 3.
Plus inside → left.

What changes

The inputs (x-values). Every point slides left or right.

What stays

The slope. The new line is parallel to the original.

Example: j(x) = 2x − 1 right 2 → j(x − 2) = 2(x − 2) − 1 = 2x − 5

Horizontal Dilation

y = f(bx)

Inside works backwards: a big b squeezes the graph.

|b| > 1

Compress: points move toward the y-axis.

0 < |b| < 1

Stretch: points move away from the y-axis.

b < 0

Reflect across the y-axis.

What changes

The inputs are multiplied by b. The x-intercept moves: 2 → 1 → 4.

What stays

The y-intercept: points on the y-axis have x = 0.

Example: f(x) = x − 2 → f(2x) = 2x − 2

Inside vs. Outside

y = a · f(b(x − c)) + d

Outside: a and d

Change the outputs → vertical

  • + d: up d
  • − d: down d
  • a: vertical stretch or compress
  • a < 0: reflect across the x-axis

Does what it says.

Inside: b and c

Change the inputs → horizontal

  • x − c: right c
  • x + c: left c
  • b: horizontal compress or stretch
  • b < 0: reflect across the y-axis

Does the opposite.

Only for f(x) = x!

Right n gives the same line as down n, and n · f(x) matches f(nx).

For other lines they are not the same. j(x) = 2x − 1:

up 4: 2x + 3   but   left 4: 2x + 7

Example: g(x) = −2 · f(x − 3) + 1
right 3 · stretch by 2 · reflect across the x-axis · up 1

Perpendicular ⊥

Meet at a right angle. Slopes are negative reciprocals: ⅔ · (−3/2) = −1.

Parallel ∥

Never meet. Slopes are the same: y = 2x + 1 ∥ y = 2x − 5.

Why? A 90° turn maps (x, y) to (−y, x), so slope b/a becomes −a/b.

Why?

Horizontal: y never changes, so slope = 0 ÷ run = 0.
Vertical: x never changes, so slope = rise ÷ 0: undefined.

Always

All horizontal lines are parallel. All vertical lines are parallel. A horizontal and a vertical line are always perpendicular.

Through (2, −1): horizontal y = −1, vertical x = 2

Write a Parallel or Perpendicular Line

y − y₁ = m(x − x₁)
  1. Find the slope of the given line.
  2. Parallel: use the same slope. Perpendicular: flip it and change the sign.
  3. Plug in the point: y − y₁ = m(x − x₁) or y = mx + b.
  4. Solve for y.

∥ to y = −3x − 1 through (−1, 5)

Same slope: m = −3

5 = −3(−1) + b

5 = 3 + b, so b = 2

y = −3x + 2

⊥ to y = 2x + 1 through (6, 2)

Flip and change: m = −½

y − 2 = −½(x − 6)

y − 2 = −½x + 3

y = −½x + 5

Check: put the point into your answer. It must make the equation true.
