Catch-Up · Lesson 1 · Activity 1.2 · Slopes of Parallel Lines · SE p. 275 · ★ Essential

Will the graphs of j(x) and q(x) ever intersect?

j(x) = 2x − 1    q(x) = 2x + 3

No. Both lines have slope 2 and stay 4 units apart, so they are parallel.

Prove it for any line. Translate line AB up a units to make line A′B′.

Pre-image: A(x₁, y₁), B(x₂, y₂)

Image: A′(x₁, y₁ + a), B′(x₂, y₂ + a)

Slope of the image:

((y₂ + a) − (y₁ + a)) ÷ (x₂ − x₁)
= (y₂ − y₁) ÷ (x₂ − x₁)
Activity 1.2, 15–20 minutes. The a's cancel, so the slopes are the same: the image is parallel to the pre-image. Ask: Why did the x-coordinates stay the same? (A vertical translation moves only up or down.)

Catch-Up · Lesson 1 · Activity 1.2 · Questions 3–4 · SE p. 276 · ★ Essential

Write the equation of a parallel line

Catalina

Parallel to y = ½x + 3 through (2, 9): the point on the line at x = 2 is (2, 4), so translate up 5.

James

Use the slope ½ and the point (2, 9): 9 = ½(2) + b, so b = 8.

y = ½x + 8

Now you: parallel to y = −3x − 1 through (−1, 5).

Parallel, so the slope is −3: 5 = −3(−1) + b, so b = 2.

y = −3x + 2

Catch-Up · Lesson 1 · Activity 1.3 · Definition · SE p. 279 · ★ Essential

Vertical dilation: y = a · f(x)

|a| > 1: the graph stretches vertically (steeper).

0 < |a| < 1: it compresses vertically (less steep).

a < 0: it also reflects across the x-axis.

For f(x) = x, the new slope is a; the y-intercept stays (0, 0).

Have students copy the definition. Watch for students who say the slope 'increases' when a = −3: it gets steeper, but the slope is −3.

Catch-Up · Lesson 1 · Summary

Translations vs. dilations

Translation f(x) + d

Moves the line up or down. Same slope; new y-intercept. Parallel lines.

Dilation a · f(x)

Stretches, compresses or reflects. New slope; for f(x) = x the y-intercept stays (0, 0).

Parallel line through a point: keep the slope, then find b with the point.

To close Day 2, have students reread the Essential Question. End of Day 2.

Catch-Up · Lesson 2 · Activity 2.1 · Definitions · SE p. 291 · ★ Essential

Horizontal vs. vertical translations

y = f(x − c)

Changes the inputs. c > 0: shift right c. c < 0: shift left.

y = f(x) + d

Changes the outputs. d > 0: shift up d. d < 0: shift down.

For f(x) = x: right n = down n, and left n = up n.

Does that work for every linear function?

Watch the sign: f(x − 3) moves right 3, f(x + 3) moves left 3.

Catch-Up · Lesson 2 · Activity 2.1 · Summary · ★ Essential

Translations of linear functions

Inside the parentheses changes the input (horizontal); outside changes the output (vertical).

f(x − c) moves right c; the sign flips.

Only for f(x) = x does right n match down n.
